# 全局乘区并入模式 + 引擎优化 + mmckb 数据还原报告

日期: 2026-08-30

## 一、全局乘区.yml 并入模式文件

原"全局乘区"分类（`multiplier.horizontal/vertical.*`、`multiplier.vertical-limit`、`multiplier.*-momentum` 共 7 键）不再作为全局配置：

| 改动点 | 内容 |
|---|---|
| 模式文件 | 新增 `multiplier:` 分节（分类三·乘区），`multiplierExplicit` 标记随显式键激活 |
| 引擎取值链 | 非对刀路径乘区：模式 `multiplier:` 显式 → 全局默认（隐藏兜底层）；对刀路径仍走 `pvp.*` 乘区 |
| 全局文件 | `全局乘区.yml` 不再生成；`CATEGORY_FILES` 仅剩 系统开关/高级机制 |
| 迁移 | 旧 `全局乘区.yml`/`基础击退.yml` 中 multiplier 组 → 各模式文件 `multiplier:` 分节（仅补缺失键），迁移后删除旧文件（实测通过） |
| 命令 | `/kb set|get multiplier.*` 重定向到当前模式文件分节（实测：`kb set multiplier.horizontal.ground 1.15` 落盘+重启保持） |
| GUI | 全局分类移除"全局乘区"；模式参数新增"乘区(原全局)"分类页（7 参数） |
| 调试工具 | `CORE_GLOBAL_KEYS` → `CORE_PROFILE_KEYS`（multiplier 7 键），`YAML_ORDER_PROFILE` 增加 multiplier 分节，导出不再包含全局乘区键 |
| 校验修复 | 动量保留 [0,1] 限制仅作用于 `base-kb.*-momentum`（此前 `multiplier.*-momentum`/`pvp.*-momentum` 乘区被误限 [0,1]，无法 >1） |

模式文件 YAML 现按 6 分类组织（基础·地面空中分离 / 对刀PVP / 乘区 / 摩擦与附加 / 疾跑 / 动态misplay + 投射物 + 引擎键覆盖）。

| 4.2~4.5 格 | 57 | 0.648 | 0.97 |
| 4.5~4.8 格 | 14 | 0.581 | 0.99 |
