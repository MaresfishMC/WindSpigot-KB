# 基础击退/对刀PVP 并入模式 + KBM式分节 整改报告

> 日期：2026-08-28
> 依据：真实服务器配置 `F:\open\新服务器\senven (2)`（只读查阅）+ dw1e/KnockbackManager 风格
> 结论先行：**应当并入（辩证确认）**；全局文件 `基础击退.yml`/`对刀PVP.yml` **停止生成**；模式文件改为 **KBM 式分节分类**。

---

## 一、需求翻译（确认理解）

1. `base-kb.*`（基础击退，7键）、`pvp.*`（对刀PVP，9键）、`horizontal/vertical.sprint-extra`（疾跑加成，2键）——这三个"击退手感"组**并入模式(profile)文件**，全局不再生成 `基础击退.yml`/`对刀PVP.yml`；
2. 模式文件采用**类似 KBM 的分节分类**（`horizontal:` / `vertical:` / `projectiles:` / `pvp:` …，当前模式文件是扁平键"模式内没有这种"）；
3. 核心与调试工具同步修改，工具转换出的两个文件适配新结构；
4. 顺带检查 bug、优化运行速率。

## 二、辩证判断：该不该并入？

**正方（并入）：**
- 上一轮已确认"配置文件作为基础KB"；base-kb/pvp 仍留在全局是**半成品**——模式切换时这些手感参数不变，出现"基础值改了模式、乘区还是全局"的分裂；
- 用户真实服务器 `senven (2)` 中 `基础击退.yml` 与模式文件并存，管理员要两处维护，KBM 用户习惯**一处一档**；
- 对刀PVP是**玩家间**行为，天然属于模式（不同模式可开/关对刀乘区）。

**反方（保守）：**
- 全局键被工具导出(knockback.yml)与 `/kb set` 引用，移除有破坏面；
- 旧服务器已有全局文件，行为不能突变。

**辩证结论：并入，但保留"兼容层"：**
- 引擎取值链改为 **模式显式字段 → 全局参数(隐藏默认)**：旧模式文件(无新分节)继续回落全局值，行为不变；
- 引擎参数注册表 **保留** 这 18 个键（作为硬编码默认与旧 knockback.yml 导入兼容），只是**不再生成/显示**对应全局文件与 GUI 分类；
- 升级迁移：检测到旧 `基础击退.yml`/`对刀PVP.yml` 时，把其中值**写入所有模式文件的新分节**（真正"并入模式"），随后删除旧文件并告警一次。

## 三、新模式文件结构（KBM 式分节）

```yaml
# ==== 近战基础击退(原全局 base-kb 并入, 地面/空中分离) ====
horizontal:
  ground: 0.35
  air: 0.35
vertical:
  ground: 0.35
  air: 0.35
# ==== 垂直钳制与动量 ====
vertical-limit: 0.4
vertical-max: 0.4
vertical-min: -1.0
horizontal-momentum: 0.5
vertical-momentum: 0.5
# ==== 疾跑额外击退(原全局 sprint-extra 并入, 绝对值) ====
sprint-extra:
  horizontal: 0.0
  vertical: 0.0
# ==== 对刀PVP独立乘区(原全局 pvp.* 并入) ====
pvp:
  enabled: true
  horizontal:
    ground: 1.0
    air: 1.0
  vertical:
    ground: 1.0
    air: 1.0
  vertical-limit: 1.0
  horizontal-momentum: 1.0
  vertical-momentum: 1.0
  sprint-extra:
    horizontal: 0.0
    vertical: 0.0
# ==== 投射物(原核心独有, KBM projectile 风格) ====
projectiles:
  rod:     { horizontal: 0.35, vertical: 0.35 }
  arrow:   { horizontal: 0.35, vertical: 0.35 }
  pearl:   { horizontal: 0.35, vertical: 0.35 }
  snowball:{ horizontal: 0.35, vertical: 0.35 }
  egg:     { horizontal: 0.35, vertical: 0.35 }
# ==== 原核心独有调整项 ====
friction: { horizontal: 2.0, vertical: 2.0 }
stop-sprint: true
extra:      { horizontal: 0.425, vertical: 0.085 }
wtap-extra: { horizontal: 0.425, vertical: 0.085 }
add:        { horizontal: 0.0, vertical: 0.0 }
sprint-multiplier: { horizontal: 1.0, vertical: 1.0 }
sprint-lenient-enabled: true
air-multiplier:    { horizontal: 1.0, vertical: 1.0 }
ground-multiplier: { horizontal: 1.0, vertical: 1.0 }
dynamic-misplay: { enabled: false, target: 0.0, compensation: 0.5 }
```

**兼容读取**：旧扁平键（`horizontal: 0.35`、`horizontal-ground`、`projectiles.rod.horizontal`…）与新分节**双格式加载**；保存一律写新分节。旧文件平滑迁移（下次 GUI 改动即重写为新结构）。
