# WindSpigot-KB 自定义PVP服务器核心

基于 WindSpigot 2.1.4（PaperSpigot 1.8.8 fork）源码定制，内置新版击退引擎，
与 `kb调试工具新版适配`（kbm调试仪.html）导出的 knockback.yml 直接兼容。

## 构建

```bat
F:\open\新服务器\PVP内核\build.bat
```
产物：`编译后文件\WindSpigot-KB-Enhanced.jar`（Java 8 可运行，velocity-native 已回退 1.1.9）。

## 击退引擎（KnockbackEngine）

击退仍分两个阶段（与原版一致，原核心引擎为基础谨慎修改）：

- **阶段一**（`EntityLiving.a()`，近战命中）：仅与双方 XZ 相对位置相关
  - `最终击退 = base-kb × multiplier`（空中/地面分开取值）
  - 双方都是玩家时（对刀）走 `pvp.multiplier.*` 独立乘区
  - 动量保留 `*-momentum`（0.5=原版除以2，0=完全覆盖原速度，借鉴 MMC friction=0 语义）
  - 可选：距离衰减（借鉴 MMC rangeFactor）、连击递增、防飞天限高（借鉴 KBM y_limit）
- **阶段二**（`EntityHuman.attack()`）：仅与攻击者 yaw 和疾跑状态相关
  - `sprint-extra` 为**绝对值累加**（不乘击退等级）
  - 击退附魔按等级叠加，沿用 profile 的 `extra-horizontal/extra-vertical`
  - 动态 misplay：按目标玩家 ping 放大击退补偿（借鉴 dw1e/KnockbackManager 思想，未照搬）

## 配置文件结构（借鉴 dw1e/KnockbackManager 多文件拆分）

```
服务端根目录/
├─ knockback.yml            指针文件(knockback.current/players) + 调试工具导入层
└─ kb配置文件/
   ├─ 基础击退.yml           基础KB配置(base-kb / multiplier / 疾跑加成 / sprint-reach)
   ├─ 对刀PVP.yml            对刀独立参数(pvp.*)
   ├─ 系统开关.yml           系统开关(stop-sprint / hit-delay / iframe-knockback 等)
   ├─ 高级机制.yml           高级机制(y-limit / range-reduction / combo / gravity / dynamic-misplay)
   └─ 模式/
      ├─ vanilla.yml        各模式KB调整(旧版profile，每个模式一个文件)
      ├─ kohi.yml
      ├─ hypixel.yml
      └─ windpvp.yml
```

- **热更新为合并语义**：`/kb reload` 时只覆盖文件中显式存在的键。
- **调试工具导入**：工具导出的 `knockback.yml` 放入根目录 → `/kb reload` → 引擎参数自动导入
  `kb配置文件/` 对应分类文件并从原文件移除，之后编辑分类文件即可。
- 旧版 `knockback.yml` 中的 `knockback.profiles.*` 首次启动自动迁移到 `模式/` 目录。

### 参数语义速查（根级键在各分类文件中，路径不变）

| 键 | 默认 | 说明 |
|---|---|---|
| base-kb.horizontal/vertical.ground/air | 0.4 | 基础击退，空中/地面分开 |
| base-kb.*-momentum | 0.5 | 受击者原速度保留比例 |
| base-kb.vertical-limit | 0.4 | 垂直击退 motY 上限 |
| multiplier.* | 1.0 | 全局乘区 |
| pvp.* | 1.0/0.0 | 对刀独立乘区与疾跑加成 |
| horizontal/vertical.sprint-extra | 0.0 | 疾跑额外击退（绝对值） |
| sprint-reach.enabled/grace-ticks/extra | false/5/0.5 | 疾跑宽松判定：停止疾跑后 N tick 内仍算疾跑，并放宽攻击距离 |
| y-limit.* | true/1.25/0.1 | 受害者高出攻击者 1.25 格后改用超限垂直击退（可为负，防连击飞天） |
| range-reduction.* | false/3.0/0.035/0.4 | 超过起始距离后每格衰减水平击退 |
| combo.* | false/0.05/0.4/40 | 连续命中水平击退递增 |
| hit-delay | 0 | 受击无敌帧 tick（0=无，对刀服推荐） |
| damage-increment | true | 无敌帧内更高伤害是否结算差值 |
| iframe-knockback | true | 无敌帧内仍产生击退 |
| server-side-kb | false | 服务端权威击退（不回滚 mot，不回传后还原） |
| lag-compensation.enabled | false | 延迟补偿命中判定（回溯位置） |
| gravity.value/air-resistance | 0.08/0.98 | 击退滞空期间的重力/空气阻力（落地自动恢复） |
| dynamic-misplay.* | false/0.0/0.5 | 按目标 ping 的动态击退补偿 |

## 指令（/kb，权限 windspigot.command.knockback，井然有序分组）

```
/kb                       总览
/kb list [分类]           按分类列出参数（基础击退/全局乘区/疾跑加成/对刀PVP/系统开关/高级机制）
/kb get <参数路径>        查询参数
/kb set <参数路径> <值>   修改参数（即时生效 + 写回 yml，支持 tab 补全）
/kb gui [分类]            箱子 GUI 点击编辑
/kb reload                热更新 knockback.yml（控制台可用）
/kb reset                 恢复全部默认
/kb profile ...           旧版 profile 系统（list/create/delete/load/set/info）
```

GUI 操作：数值参数 **左键+步长 / 右键-步长 / Shift 10倍**；布尔参数点击切换；
改动即时生效并自动保存。

## 调试工具配合

1. 打开 `kb调试工具新版适配\kbm调试仪.html`
2. 用经典二分/黄金分割/插值反推模块调参
3. 导出（组合导出现在直接命名为 `knockback.yml`）
4. 放入服务端根目录 → 游戏内 `/kb reload` 即时生效
